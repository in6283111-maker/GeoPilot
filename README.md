# GeoPilot — макеты для Figma

Учебный проект туристического приложения для области Жетісу.

## Скачать

- [Схема User Flow (SVG)](figma/GeoPilot-UserFlow.svg)
- [Пять экранов (SVG)](figma/GeoPilot-Screens.svg)
- [Полный комплект, включая отдельные экраны (ZIP)](figma/GeoPilot-Download.zip)

Откройте нужный файл на GitHub и нажмите **Download raw file** (значок скачивания). Для архива также доступна кнопка **View raw**.

Распакуйте архив и перетащите SVG на холст Figma Design. Схема и оформление уже готовы. SVG не сохраняет интерактивные переходы: свяжите экраны во вкладке Prototype. Подробная инструкция находится внутри архива.

Карты схематичные, ИИ-ответы демонстрационные; GPS и настоящая навигация не подключены.
